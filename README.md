# killall-craft

Programming principles as agent skills. Each skill is one principle, loaded at the moment it applies,
with pointers to real code that shows it.

| Skill | Loads when |
|---|---|
| `house-rules` | Writing, changing, or reviewing any code |
| `parse-dont-validate` | Input crosses a trust boundary |
| `make-the-change-easy` | A change fights the existing code |
| `smell-to-refactoring` | Reviewing a diff, or code feels wrong |

Install:

```sh
/plugin marketplace add killallgit/killall-craft
/plugin install killall-craft@killall-craft
```
